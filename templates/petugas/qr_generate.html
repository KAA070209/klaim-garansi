Ketentuan QR Code

  • Setiap unit memiliki satu nomor seri unik.
  • Setiap unit memiliki satu token QR unik.
  • QR Code mengarah ke halaman publik /qr/<token>.
  • Token tidak menggunakan ID database secara langsung.
  • QR Code dapat dicetak dari daftar unit QR.
